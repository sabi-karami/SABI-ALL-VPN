SABI ALL VPN

یک دستور، سی کارت اتصال، یک پنل خصوصی فارسی

نصب خودکار روی سرور تازهٔ Ubuntu 24.04 یا ساخت خودکار سرور در AWS — با کلید و رمز تازه برای هر نصب.

نسخهٔ آزمایشیv1.0.0-beta.4Ubuntu 24.04 amd64AWS + CloudflareMIT
گـ

۱سرور آماده دارید

روی سرور تازهٔ Ubuntu 24.04 amd64 از طریق SSH اجرا کنید. curl، Python 3 و venv اگر نباشند خودکار نصب می‌شوند.

bash <(curl -fsSL https://raw.githubusercontent.com/sabi-karami/SABI-ALL-VPN/v1.0.0-beta.4/bootstrap.sh)

۲سرور در AWS ساخته شود

روی Linux، WSL یا macOS با حساب AWS احراز هویت‌شده. پیش‌نیازها خودکار نصب می‌شوند.

bash <(curl -fsSL https://raw.githubusercontent.com/sabi-karami/SABI-ALL-VPN/v1.0.0-beta.4/bootstrap.sh) --aws
⚠️ پس از تأیید CREATE هزینه‌زا است (EC2، EBS، IPv4، ترافیک). سقف هزینهٔ خودکار ندارد.

نقشهٔ اتصال‌ها

پنل خصوصی فارسی

کلیک روی هر مقدار = کپی. رمزها پیش‌فرض پنهان‌اند، آموزش هر روش و دانلود فایل‌ها بعد از ورود.

مسیر نصب

پس از پرسش‌های اولیه، نصب در سرویس systemd ادامه می‌یابد و با --resume از آخرین checkpoint ادامه پیدا می‌کند.

پیش از نصب بدانید

صادقانه: این چیزها را تضمین نمی‌کنیم.

⏳

هنوز آزمایشی است

نصب کامل fresh-host و AWS انتهابه‌انتهای این نسخه هنوز انجام نشده. اول روی ماشین disposable امتحان کنید.

🖥️

فقط سرور اختصاصی

Ubuntu 24.04 amd64 تازه. روی سروری که سرویس دیگری دارد اجرا نکنید؛ rollback کامل وجود ندارد.

🔐

رازها خصوصی می‌مانند

هیچ رمز واقعی در مخزن نیست. ZIP خصوصی رمزنگاری‌شده نیست؛ هرگز آن را عمومی نکنید.

🌐

بدون تضمین عبور

فیلترینگ، DNS، سیاست دیتاسنتر و کلاینت‌ها متفاوت‌اند. وضعیت پنل تست اتصال از اینترنت شما نیست.

🧭

IPv4 در اولویت

مسیر IPv6 در فایل‌های WG/AWG تنظیم نشده؛ IPv6 را روی کلاینت مدیریت کنید. تضمین عدم نشت نیست.

📖

پنل read-only

فروش اشتراک، ساخت کاربر و حسابداری مصرف ندارد؛ برای مالک سرور طراحی شده است.
