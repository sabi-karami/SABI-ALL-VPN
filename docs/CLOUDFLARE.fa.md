# Cloudflare، DNS و گواهی

## حالت خودکار توصیه‌شده

توکن محدود به یک Zone با مجوزهای **DNS Edit، Zone Read، Zone Settings Read** بسازید. توکن را فقط در prompt مخفی ترمینال وارد کنید. از Global API Key استفاده نکنید.

پیشوند `allvpn` روی `example.com` این رکوردها را می‌سازد:

| نوع | نام | مقدار | Proxy |
|---|---|---|---|
| A | allvpn.example.com | IPv4 سرور | خاموش |
| A | allvpn-cdn.example.com | IPv4 سرور | روشن |
| A | allvpn-ns.example.com | IPv4 سرور | خاموش |
| NS | allvpn-t.example.com | allvpn-ns.example.com | ندارد |

اگر رکورد موجود با مقدار/نوع موردنظر تعارض داشته باشد، نصب **متوقف** می‌شود؛ رکورد قبلی بازنویسی نمی‌شود. از پیشوند تازه استفاده کنید. فهرست رکوردهای ایجادشده در `dns-created.json` ثبت می‌شود.

Zone SSL باید Full یا ترجیحاً Full (strict) باشد؛ اسکریپت تنظیم سراسری Zone را تغییر نمی‌دهد. گواهی RSA 2048 با DNS-01 برای نام مستقیم و نام CDN گرفته می‌شود؛ RSA به‌خاطر سازگاری SoftEther است. به این ترتیب Full(strict) می‌تواند گواهی origin را نیز بررسی کند.

فایل `/etc/sabi-allvpn/certbot-cloudflare.ini` برای تمدید گواهی باقی می‌ماند و root-only است. هیچ توکن Cloudflare در پنل، ZIP عمومی یا فایل مشتری وجود ندارد. گواهی‌ها به‌صورت hook پس از renew در سرویس‌ها اعمال می‌شوند؛ وقفهٔ کوتاه اتصال هنگام restart ممکن است رخ دهد.

## حالت DNS دستی

در wizard رکوردها را ایجاد کنید. **هنگام صدور گواهی، A مستقیم و A مربوط به CDN هر دو DNS-only باشند** تا HTTP-01 از پورت 80 به سرور برسد. پس از تکمیل گواهی، فقط رکورد CDN را proxied کنید. پورت 80 برای HTTP-01 لازم است. پس از روشن‌کردن proxy، تمدید بعدیِ نام CDN با standalone ممکن است شکست بخورد؛ پیش از تاریخ انقضا به DNS-01 مهاجرت کنید یا در زمان تمدید رکورد CDN را موقتاً DNS-only کنید. برای تمدید خودکار بدون این کار دستی از حالت Cloudflare API استفاده کنید. رکوردهای دیگر مستقیم بمانند.

## محدودیت‌ها

- سرویس proxy معمول Cloudflare تونل عمومی هر TCP/UDP نیست؛ فقط کارت‌های WS/XHTTP که برای CDN ساخته شده‌اند از آن می‌گذرند.
- پنل روی 9444 مستقیم است؛ Cloudflare proxy عادی این پورت را پوشش نمی‌دهد.
- WebSocket باید برای Zone مجاز باشد. WAF/Challenge/Access ممکن است اتصال کلاینت را بشکند؛ تنظیم هدفمند روی hostname انجام دهید، نه غیرفعال‌کردن امنیت کل Zone.
- هیچ تضمینی برای عبور از تمام شبکه‌ها، فیلترینگ یا تغییر سیاست Cloudflare وجود ندارد.
- ساخت DNS معتبر و دامنه با اختیار شما پیش‌نیاز است؛ نصب‌کننده دامنه ثبت نمی‌کند.
