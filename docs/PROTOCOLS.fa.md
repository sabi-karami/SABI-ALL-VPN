# راهنمای روش‌های اتصال
مقادیر `${...}` در زمان نصب تولید و در پنل جایگزین می‌شوند. هیچ رمز واقعی اینجا نیست.
این صفحات انتخاب کلاینت و مسیر ورود اطلاعات را توضیح می‌دهند؛ سازگاری همهٔ نسخه‌های کلاینت تضمین نمی‌شود.

اتصال مستقیم، هستهٔ Xray
پورت: `443 / TCP`

1. v2rayNG در اندروید یا v2rayN با هستهٔ Xray مناسب است.
2. یک کلاینت سازگار با این روش نصب کنید.

4. پروفایل را انتخاب و متصل شوید؛ اگر برنامه اجازهٔ VPN خواست، تأیید کنید.
5. در مرورگر IP خروجی را بررسی کنید؛ برای مسیرهای این سرور باید ${IP} دیده شود.

## IKEv2 / IPsec
احراز هویت با گواهی کلاینت
پورت: `500 + 4500 / UDP`

1. اندروید: strongSwan VPN Client را نصب و فایل allvpn.sswan را وارد کنید؛ اگر گواهی خواسته شد allvpn.p12 را وارد کنید.
2. iOS و macOS: allvpn.mobileconfig را دانلود و فقط پس از بررسی نام سرور، از تنظیمات دستگاه پروفایل را نصب کنید.
3. ویندوز: allvpn.p12 را در مخزن گواهی مناسب کلاینت VPN وارد کنید و VPN از نوع IKEv2 با احراز هویت گواهی بسازید؛ تنظیم مخزن CA و گواهی دستگاه ممکن است لازم شود.
4. فایل P12 رمز ندارد؛ در پرسش رمز، خالی بگذارید. آدرس و Remote ID باید با دامنهٔ همین کارت منطبق باشد.

**نکته:** این تنظیم IKEv2 مبتنی بر گواهی است؛ کاربر/رمز L2TP را به‌جای گواهی وارد نکنید.
فایل‌ها: `allvpn.mobileconfig`, `allvpn.sswan`, `allvpn.p12`

## SSTP

پورت: `5555 / TCP`

1. کلاینت SSTP که پورت سفارشی قبول کند نصب کنید؛ مثلاً Open SSTP Client در اندروید.
2. سرور را با پورت 5555 وارد کنید؛ نام کاربر و رمز همین کارت را وارد کنید.
3. بررسی گواهی TLS روشن بماند؛ بعد متصل شوید.

**نکته:** این سرویس روی 443 نیست؛ اتصال با کلاینتی که پورت 5555 را نپذیرد ممکن نیست.

## SoftEther VPN
سرویس SoftEther با گواهی معتبر
پورت: `5555 / TCP`

1. SoftEther VPN Client را نصب و یک Virtual Network Adapter بسازید.
2. در New VPN Connection سرور و پورت 5555 را وارد کنید؛ Virtual Hub را DEFAULT قرار دهید.
3. Password Authentication را انتخاب و حساب این کارت را وارد کنید.
4. متصل شوید و مسیر خروجی را بررسی کنید.

**نکته:** این سرویس روی 443 نیست؛ اتصال با کلاینتی که پورت 5555 را نپذیرد ممکن نیست.

## PPTP · قدیمی
فقط برای سازگاری قدیمی؛ توصیه نمی‌شود
پورت: `1723 / TCP + GRE`

1. ترجیحاً به‌جای این روش از WireGuard، OpenVPN یا IKEv2 استفاده کنید.
2. فقط برای آزمایش در کلاینت پشتیبان PPTP، سرور و حساب این کارت را وارد کنید.
3. اگر اتصال برقرار نشد، GRE هم باید در مسیر شبکه قابل عبور باشد؛ بازبودن TCP به‌تنهایی کافی نیست.

**نکته:** PPTP امنیت قابل اتکایی ندارد؛ برای اطلاعات حساس استفاده نکنید.

## MTProto · Telegram
پروکسی فقط برای تلگرام
پورت: `4433 / TCP`

1. لینک وب تلگرام را کپی و در مرورگر باز کنید.
2. در تلگرام گزینهٔ افزودن / Enable proxy را تأیید کنید.
3. راه دستی: Settings → Data and Storage → Proxy → MTProto؛ سرور، پورت و secret را از لینک وارد کنید.

**نکته:** این پروکسی کل اینترنت یا مرورگر را پوشش نمی‌دهد.
فایل‌ها: `telegram-mtproto.txt`

## Tor · obfs4 Bridge
پل خصوصی برای ورود به شبکهٔ Tor
پورت: `7443 / TCP`

1. Tor Browser رسمی را نصب کنید.
2. در تنظیمات Connection / Bridges گزینهٔ ارائهٔ پل دستی را انتخاب کنید.
3. مقدار «خط پل برای Tor Browser» را کپی کنید؛ شامل obfs4، IP، fingerprint و cert است.
4. پل را ذخیره و Connect را بزنید.

**نکته:** IP خروجی Tor آدرس یکی از خروجی‌های شبکهٔ Tor است، نه الزاماً IP این سرور.
فایل‌ها: `tor-obfs4-bridge.txt`

## SSH · SOCKS Tunnel
پروکسی محلی روی تونل SSH
پورت: `22 / TCP`

1. فایل کلید خصوصی ssh-tunnel-key را دانلود کنید.
2. در macOS/Linux روی فایل chmod 600 ssh-tunnel-key اجرا کنید؛ در ویندوز دسترسی فایل را به حساب خود محدود کنید.
3. فرمان همین کارت را در پوشهٔ فایل اجرا کنید. در اولین اتصال fingerprint سرور را با بخش اطلاعات سرور مقایسه کنید.
4. پروکسی برنامه را SOCKS5 و آدرس 127.0.0.1:1080 بگذارید؛ ترمینال را باز نگه دارید.

**نکته:** حساب tunnel برای تونل است؛ شِل تعاملی ندارد.
فایل‌ها: `ssh-tunnel-key`, `ssh-tunnel-key.pub`

## dnstt · DNS Tunnel
مسیر اضطراری، معمولاً کندتر
پورت: `53 / UDP (سرور)`

1. باینری مناسب سیستم را دانلود کنید: Linux x86-64، Windows x86-64 یا macOS ARM64.
2. در لینوکس/macOS مجوز اجرا بدهید: chmod +x نام‌فایل. در macOS نام فایل فرمان را با dnstt-client-mac-arm64 جایگزین کنید.
3. فرمان را اجرا کنید و برنامه را باز نگه دارید.
4. پروکسی برنامه را SOCKS5 روی 127.0.0.1:7000 تنظیم کنید.

**نکته:** دسترسی به resolver انتخابی لازم است؛ هیچ resolver در همهٔ شبکه‌ها قابل دسترس نیست. این روش برای دانلود حجیم مناسب نیست.
فایل‌ها: `dnstt-client-linux`, `dnstt-client.exe`, `dnstt-client-mac-arm64`, `dnstt-server.pub`
